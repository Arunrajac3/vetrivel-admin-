📦 Bulk JSON Import

JSON array பேஸ்ட் பண்ணவும். ஒவ்வொரு object-ம் இந்த format-ல் இருக்கணும்:
{"c":"Topic name","q":"Question text","o":["opt1","opt2","opt3","opt4"],"a":0,"e":"Explanation"}

📄 PDF Import — தமிழ் PDF இருந்து வினாக்கள்

PDF upload பண்ணவும் → உரை extract ஆகும் → கீழே "வினாக்களாக பிரி" பட்டனை அழுத்தி ஒவ்வொரு வினாவையும் தனித்தனி பெட்டிகளில் எளிதாக edit பண்ணலாம் → சரிபார்த்து Firestore-க்கு upload பண்ணலாம்.
Pattern: 1. கேள்வி... A) ... B) ... C) ... D) ... Answer: B

🗑️ Bulk Delete — வினாக்களை நீக்கு

கீழே table-ல் தேவையான வினாக்களை checkbox மூலம் தேர்வு செய்யவும், அல்லது மேலே Filter பண்ணி "Filter செய்யப்பட்ட அனைத்தையும்" ஒரே முறையில் நீக்கலாம். இது Undo செய்ய முடியாது.
0 வினாக்கள் தேர்வு செய்யப்பட்டன

⚡ Selective export (everyday use)

புது unit add / correction → அந்த file மட்டும் download + GitHub replace. Full 31 files வேண்டாம்.

Export unit = அந்த class questions மட்டும் + updated series-index.json.
